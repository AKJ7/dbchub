# Privacy Notice

dbchub is designed to collect as little personal data as possible. It is a static site
with no backend application server and no account system of its own.

## What we do and don't collect

- **No server-side accounts or databases.** The site is served as static files.
- **GitHub tokens stay in your browser.** The upload feature uses a token you enter to
  call GitHub's API (`api.github.com`) directly from your browser. The token is **never**
  sent to or stored by this project. If you tick "remember token on this device", it is
  stored only in your browser's `localStorage` on that device; untick it or clear your
  browser data to remove it.
- **Contributions are public.** When you open a Pull Request or commit, the information
  GitHub records — including your username, the name and email in your commit, and your
  DCO sign-off — becomes part of the public, permanent git history. Use an email you are
  comfortable publishing.

## Third parties

- **GitHub** hosts the repository, runs the Pull Request / API flow, and (via GitHub
  Pages) serves the site. Your use is subject to GitHub's own privacy policy.
- If you self-host the site elsewhere, that host's logging and privacy terms also apply.

## Your rights

Because we hold essentially no personal data outside public git history, most requests
(access, deletion) concern data held by GitHub and should be directed to GitHub. For the
removal of a specific contribution from this repository, see [`TAKEDOWN.md`](TAKEDOWN.md).
